# IMPORTANT:
# This app must remain compatible with Python 3.14 (current Streamlit Cloud default).

# Streamlit Cloud uses the `uv` installer and may ignore runtime.txt or
# .python-version depending on provisioning order. In practice, the platform
# Python version may not be reliably overridden.
#
# Therefore:
# - ALL packages must have prebuilt cp314 wheels
# - Avoid any package that triggers source builds (will fail in Cloud)
#
# If a package version fails:
# → Check for cp314 wheel support on PyPI before pinning
#
# Strategy:
# - Prefer version ranges (>=,<) over strict pins where safe
# - Avoid system dependencies (no packages.txt unless absolutely required)
# - Prioritise wheel-only installation paths
# ════════════════════════════════════════════════════════════════════════════
