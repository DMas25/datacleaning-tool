# ColtraDataAi — Output Specification

## Scope

ColtraDataAi produces three classes of output:

| Class                | Format       | Generated by              |
|----------------------|--------------|---------------------------|
| Excel workbook       | `.xlsx`      | `core/report_builder.py`  |
| PDF executive summary| `.pdf`       | `core/pdf_report.py`      |
| Live dashboard       | Streamlit UI | `ui/results_panel.py`     |

All three surfaces share the same data: charts are rendered once in
`core/chart_gallery.py` and embedded in both the Excel and PDF files.

## Excel Workbook Structure

### Sheet order and tab colours

| #  | Sheet name        | Tab colour  | Contents                                              |
|----|-------------------|-------------|-------------------------------------------------------|
| 1  | Report Summary    | `#1F4E79`   | Cover: logo, title, metrics, ToC with hyperlinks      |
| 2  | Raw Data          | `#8DA9C4`   | Original uploaded dataset, unmodified                 |
| 3  | Cleaned Data      | `#2E86AB`   | Post-cleaning dataset with auto-filter and freeze     |
| 4  | Cleaning Log      | `#4472C4`   | Step-by-step log of operations applied                |
| 5  | Quality Checks    | `#F59E0B`   | Top-line quality metrics + column-level risk breakdown|
| 6  | Processing Notes  | `#9CA3AF`   | Assumptions and rules applied during processing       |
| 7  | Data Insights     | `#48C9B0`   | Descriptive observations (non-advisory)               |
| 8  | Executive Summary | `#1F4E79`   | 2-column KPI grid + embedded premium chart gallery    |
| 9  | Dashboard         | `#46D324`   | Charts, completeness %, risk table, status summary    |

### Formatting standards

- All sheets: freeze panes at row 2, auto-filter on data columns
- Header rows: height 22 px, bold, primary colour text on secondary fill
- Title rows: height 20 px, bold, white text on primary background
- Body rows: standard height, bordered, blank-cell highlight (`#FFF2CC`)
- Column widths: auto-sized to content, capped at 28 characters

## PDF Executive Summary Structure

### Page layout
- Page size: A4 portrait
- Margins: 20 mm left/right, 18 mm top, 24 mm bottom (footer space)
- Page footer: `{footer_line}  ·  Page N` (right-aligned page number)
- Footer hairline rule at 17 mm from bottom

### Content sequence

1. Logo image (40 mm width)
2. App name (22 pt, primary colour)
3. Tagline (9.5 pt, muted, letter-spaced)
4. Generation timestamp
5. HR divider (primary colour, 1.5 pt)
6. **KPI table** — 4-row × 4-col: Original Rows, Cleaned Rows, Rows Removed, Columns, Missing Values, Completeness, Overall Risk (colour-coded), Top Issue
7. **Data Quality Risk Mix** — table with High/Medium/Low counts + status descriptions
8. Average issue rate caption
9. **Visual Highlights** section header
10. Per-chart: title → caption → embedded PNG image
11. Non-advisory disclaimer
12. Contact line

### Risk colour coding in PDF

| Level  | Text colour | Cell background |
|--------|-------------|-----------------|
| High   | `#DC2626`   | `#FEF2F2`       |
| Medium | `#D97706`   | `#FFFBEB`       |
| Low    | `#16A34A`   | `#F0FDF4`       |

## Live Dashboard Structure (Streamlit)

### Always-visible (all tiers)

- **Step 1:** File upload widget
- **Step 2:** Cleaning options (3 checkboxes + null handling selectbox)
- **Step 3:** Raw data preview (10 rows) + summary metrics
- **Step 4:** Process button
- **Post-processing KPI banner:** 5 cards — Original Rows, Cleaned Rows, Rows Removed, Completeness %, Overall Risk (colour-coded)
- **Step 5 base charts:** Missing Values by Column (bar), Original vs Cleaned Rows (bar)

### Pro/Enterprise only

- Premium Chart Gallery (auto-generated, mirrors Excel/PDF)
- Distribution Analysis (numeric histogram + categorical frequency)
- Trend Analysis (date-time line chart, if date column detected)
- Correlation Analysis (heatmap, if 2+ numeric columns)
- Top/Bottom Analysis (top categories + highest/lowest values)
- **Step 6:** AI Data Insights (descriptive observations)
- **Step 7:** Download buttons (Excel + PDF)

## Non-Advisory Constraint

No output — Excel, PDF, or dashboard — may include:
- Business recommendations
- Financial, legal, tax or compliance interpretations
- Predictive assertions or forward-looking statements

Every insight, observation, or flag must be descriptive of the data as-is.
The disclaimer text defined in `branding["report_disclaimer"]` must appear in every report output.
